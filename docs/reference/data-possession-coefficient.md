# `pippen.data.possession_coefficient`

Measures what fraction of free throw attempts actually consume a possession,
per season, instead of assuming the conventional 0.44.

Measured across all 25 seasons hoopR publishes, every one sits below 0.44, and
the spread across a quarter century is smaller than the average distance from
the convention. See [the errata](../methodology/errata.md) for the full table
and for why the exclusion rule decides the answer.
